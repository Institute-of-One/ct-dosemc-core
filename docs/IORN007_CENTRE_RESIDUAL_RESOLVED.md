## 1. 結論

**centre の −0.80% は、次の 2 項の積にちょうど分解されます。**

```
−0.798%  =  −0.579%   PENELOPE が 4 コード平均より低い
          × −0.221%   ct_dosemc_core が PENELOPE より低い
```

（検算：11.3162/11.3821 = 0.99421、11.2912/11.3162 = 0.99777、積 0.99202 = −0.798%。一致します。）

**つまり −0.80% のうち、自分たちの残差は −0.22% だけです。**
残りの −0.58% は「PENELOPE が 4 コード平均の下側にいる」という、参照側の性質です。

そして MC-GPU の断面積は **PENELOPE 2006 の PENDBASE 光子サブセット**です。
同じ断面積系を使うコードに対して −0.22% で一致し、
異なる断面積系を混ぜた平均に対して −0.80% ずれる ―― これは欠陥ではなく、**予期される挙動**です。

## 2. これが断面積の署名であって、幾何や正規化の誤りではない理由

**TG-195 Case 4 / 120 kVp / t = 10 mm / second test / discrete（4 コード平均からの偏差）**

| | centre | 偏差 | perimeter | 偏差 |
|---|---|---|---|---|
| EGSnrc | 11.3956 | +0.12% | 39.7663 | +0.01% |
| Geant4 | 11.4314 | +0.43% | 39.7477 | −0.03% |
| MCNP | 11.3853 | +0.03% | 39.7286 | −0.08% |
| **Penelope** | **11.3162** | **−0.58%** | **39.8029** | **+0.10%** |
| 4 コード平均 | 11.3821 | — | 39.7614 | — |
| **ct_dosemc_core** | **11.2912** | **−0.80%** | **39.7748** | **+0.03%** |
| コード間ばらつき | | **1.01%** | | **0.19%** |

読み取れる3点：

### 2.1 PENELOPE は centre で最低、perimeter で最高 ―― 符号が逆

そして **ct_dosemc_core はその符号パターンを両方で追随しています**（−0.80% / +0.03%）。

**幾何・立体角・正規化・スペクトルの誤りは、両 VOI を同じ向きに動かします。**
片方を下げて片方を上げることはできません。
符号が逆に出るのは、**エネルギー依存性を持つ量 ―― すなわち断面積**しかありません。

### 2.2 コード間ばらつきが centre で 5.4 倍大きい

centre 1.01% / perimeter 0.19% = **5.4×**。

これも同じことを言っています：

* **perimeter は一次線支配**（線源側の 1 cm 深、ほぼ非減弱） → 断面積の差が効かない
* **centre は 16 cm の PMMA を通った散乱線支配** → μ のわずかな差が指数で増幅される

4 つのコードは 4 つの異なる光子断面積ライブラリを使っています。
**centre は断面積ライブラリの違いを増幅する量である**、というのがこの 5.4 倍の意味です。

### 2.3 PENELOPE との差も同じ比を示す

* centre：ours vs PENELOPE = **−0.221%**
* perimeter：ours vs PENELOPE = **−0.071%**
* 比 = 3.1× ―― コード間ばらつきの比 5.4× と同じオーダー

つまり **PENELOPE との残差も、centre で増幅されるという同じ構造**に乗っています。
断面積系が同じなのに残るこの −0.22% は、
断面積そのものではなく、**輸送実装の差**（Woodcock トラッキング、束縛効果の扱い、
補間、エネルギーグリッド）に帰せられる大きさです。

## 4. §3 の disc/cont 比較 ―― 説明を差し替えてください

### 4.1 「×225 の振れの求積」は centre には適用できません

`docs` の説明は
「36 点求積が ×225 振れる関数の連続極限のわずか上に来るのは符号として正しい」
となっていますが、**表には centre も入っています。**

centre VOI は回転軸上にあり、円柱対称ファントムに対して
**ガントリ角に対して定数**です。定数に対する台形則（等間隔・周期）は**厳密**で、
離散 − 連続の期待値は **恒等的にゼロ**です。

これはまさに、G2 の −3.2% の原因から回転を除外したときに使った論法です。
ここで逆の論法を使うと、**同じ文書の中で矛盾**します。査読者に見つかります。

**データも矛盾しています。** 実際に ×209 振れるのは perimeter のほうですが、
差は perimeter が **+0.107%**、centre が **+0.331%** ―― 求積の話なら逆でなければおかしい。

### 4.2 正しい説明：自分たちの G4 の結果を適用すれば、有意ではありません

| | disc36 | cont720 | 差 | 引用 σ での有意性 |
|---|---|---|---|---|
| centre | 11.32513 ± 0.005057 | 11.28775 ± 0.005041 | +0.331% | 5.24σ |
| perimeter | 39.79872 ± 0.00939 | 39.75602 ± 0.009378 | +0.107% | 3.22σ |

ただし **G4 が測定したとおり、この σ は replica SD を 1.89〜4.00 倍 過小評価**しています。
適用すると：

| | ×1.89 | ×2.39 | ×4.00 |
|---|---|---|---|
| centre | 2.76σ | 2.18σ | 1.31σ |
| perimeter | 1.69σ | 1.34σ | 0.80σ |

**どちらも統計ゆらぎと矛盾しません。**

そして論文にはこちらのほうが強い文が書けます：

> 参照データで両下位ケースを提出した 2 コードは、自身の 2 つの結果が
> centre で +2.23% / +2.51% 食い違う。本パイプラインの 2 つの下位ケースは
> **統計不確かさの範囲内で一致した**（+0.33% / +0.11%、replica 較正済み σ で 2.8σ 以下）。

「理由をつけて 0.33% を説明する」より、「有意でない」のほうが強い主張です。

### 4.3 これは体系的な問題です

**G4 で σ の過小評価が確定したのに、その直後の比較で未補正の σ が使われています。**

* replica 推定は **first test の 4 セグメントでしか走っていません**。
  second test の centre / perimeter については膨張係数が未測定です。
* **second test の VOI でも replica を走らせ、膨張係数を results JSON に載せてください。**
  そして σ を有意性判定に使うすべての箇所でそれを適用する。
  でないと、小さすぎると分かっている σ で判定を続けることになります。

## 5. K = 1 の数字を絶対にアンカーとして引用しないこと

同一条件（2×10⁸ ヒストリ、36 投影、40 cm、空気 30 cm、0.25 cm ボクセル）で K だけ違います：

| K | centre | 4 コード平均比 | 包絡線内 | perimeter |
|---|---|---|---|---|
| **1** | 11.32513 | −0.50% | **True** | 39.79872 |
| **4** | 11.29124 | −0.80% | **False** | 39.77480 |

**K=1 のほうが参照とよく合います。しかしそれは偶然です。**
K=1 は立体角を **+1.14% 過大**に取る構成で、その過剰が centre を +0.30% 押し上げているだけです。
K=4 の残差は +0.067%、K=8 で +0.014% なので、**物理的に正しいのは K≥4 のほう**です。

Ω 誤差からの外挿では K=4 → K=8 の変化は約 0.014% にとどまるはずなので、
**K=4 は既に収束していると見込まれ、−0.80% の原因ではありません。**
ただし確認は必要です（§6.1）。

**「一致がよくなるから K を下げる」は絶対にしないこと。**
この注意を `docs/MC_SOURCE_MODEL.md` に明記してください。
disc/cont 比較を K=1 で走らせた判断（バイアスが対で相殺する）は正しいので、
**その2つの数字は「自己整合性の実証専用」とラベルし、G2 アンカー値と分離**してください。

### 6.2 G2 アンカーを、文書化された既定値で取り直す

G3 で「空気パスは焦点まで含めるのが既定」に変わりましたが、
**`G2_final` は `air_margin_cm = 30.0` で計算されています。**

### 6.3 上流への 5 件目（低優先だが上流には価値が高い）

「Compton で減速した光子が断面積テーブル下限を割ると、残余エネルギーが**破棄**される」
という発見（`:311`, `:372`）は、**エネルギー非保存**です。

120 kVp・PMMA では 1 keV/5 keV テーブルの差が ≤0.012% で無視できる、という測定は妥当です。
**ただし MC-GPU の主用途はマンモグラフィ／トモシンセシス（20–40 kVp）です。**
そのエネルギー帯では、テーブル下限まで減速する光子の割合がはるかに大きくなります。

**「本件は 120 kVp では無視できるが、本コードの主たる適用領域である
マンモグラフィ energies では影響が大きい可能性がある」**という形で、
issue #22–#25 のスレッドにコメントするか、5 件目として出す価値があります。
上流にとって最も有用な指摘になり得ます。
